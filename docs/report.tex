\noindent Source code: \url{https://github.com/yanruoz/gen-model-agent}\quad BIOS 774, Project 2

\section{System architecture}

The agent takes a dataset folder and a free-text objective and runs with one command:
\code{./run.sh <dataset> "<objective>"}. \code{run.sh} creates an isolated Python environment (\code{venv/}), downloads
the dataset's file if missing (checked against its declared MD5 checksum), and starts Claude Code in headless mode
(\code{claude -p}) with the agent's instructions (\code{AGENT.md}) as an appended system prompt. The run loads no user or
project settings. A permission file lets the agent run only \code{venv/bin/python scripts/*}, read the repository, and
write under \code{outputs/}; anything else is denied without a prompt, so a run never stalls waiting for a person.

The design separates \emph{deciding} from \emph{computing}. The language model reads the data profile and five
\emph{skill} files (Markdown decision rules for objective interpretation, preprocessing, model selection, downstream
use, and reporting) and writes its decisions as JSON. Every number and figure comes from deterministic, seeded Python
scripts. Each stage reads and writes JSON under \code{outputs/<dataset>/}, so any stage can be rerun on its own:

\begin{enumerate}
\item \textbf{Profile} (\code{profiler.py}): size, modality (image or tabular), whether values are counts, sparsity,
  class balance.
\item \textbf{Interpret the objective} into \code{objective.json}: task, success criterion, and a decision:
  \emph{proceed}, \emph{proceed\_adapted} (run a related task that can be tested on this data, and say so), or
  \emph{decline}. Checked by \code{validate_objective.py}.
\item \textbf{Plan} (\code{plan.json}): held-out split, preprocessing, models, hyperparameters, and seeds, each with a
  dataset-specific reason. Checked by \code{validate_plan.py}.
\item \textbf{Execute} (\code{run_plan.py}): preprocess once; train, generate, and evaluate each model and seed; run the
  test for the objective (Section 2); draw figures.
\item \textbf{Critique}: a separate Claude instance (the \code{gen-critic} subagent) sees only the objective, plan,
  metrics, and training logs, not the main agent's reasoning. It checks whether any metric tests the success criterion,
  whether the reference values are sensible, whether seeds agree, whether training ran long enough, copying and
  privacy-claim risk, and whether results contradict the stated reasons. The agent then makes exactly one plan revision.
\item \textbf{Recommend} downstream uses in \code{recommendation.json}, checked by \code{validate_recommendation.py}.
\item \textbf{Report}: the agent writes \code{findings.md}; \code{report.py} builds the PDF from the JSON files.
\end{enumerate}

Implemented models (PyTorch, small enough for a laptop): for tabular data, a variational autoencoder (VAE) with a
negative-binomial (NB, for counts), Gaussian, or Bernoulli output, and a RealNVP normalizing flow; for images, a
class-conditional convolutional VAE, a conditional generative adversarial network (GAN; projection discriminator, hinge
loss), and a conditional diffusion model (small UNet, classifier-free guidance, DDIM sampler).

\section{How the agent makes generative-modeling decisions}

\textbf{Whether to model.} \code{validate_objective.py} enforces data checks in code. Too few samples means decline. A
task that needs labels on unlabeled data, or a task with no implemented test on this modality (for example uncertainty
quantification), must be declined or adapted, so the agent never trains models whose output nobody can judge.
Near-balanced classes (largest/smallest class ratio below 1.5) cannot be treated as an imbalance problem. For class
balancing, a \textbf{headroom check} first trains the same classifier (three seeds) on real data, on real data with the
rare class resampled, and on real data plus \emph{new real} images of the rare class left out of the training
subsample. New real data is the best any generator could do. If it does not beat resampling, the plan trains a single
generator only to confirm this, and the recommendation expects resampling to be enough.

\textbf{Which model.} Each family has a fixed capability profile (exact likelihood, latent space, conditional
generation, reconstruction), and \code{validate_plan.py} rejects a model that lacks what the task needs, for example a
GAN for anomaly detection, since it has no likelihood. The model-selection skill picks \emph{one} primary model from the
objective and data (an NB VAE on raw counts for single-cell data, conditional diffusion for labeled images) and allows at
most one comparator, with a stated reason. The aim is to serve the objective, not to rank every model.

\textbf{Hyperparameters} come from heuristics keyed to the profile: latent size by sample count, epochs as a maximum with
early stopping on a validation slice of the training data, and per-epoch timings to fit the time budget. Every value
needs its own reason; the validator rejects placeholders such as ``default''.

\textbf{Evaluation} is fixed per modality, not chosen by the agent, and always uses held-out real data. Tabular data is
compared in a principal-component (PCA) space limited to components that generalize to held-out data; images are compared
in the 128-dimensional features of a small convolutional neural network (CNN) classifier trained on the real images. Metrics:
\emph{C2ST} (classifier two-sample test: the area under the ROC curve, AUC or AUROC, of a classifier separating synthetic
from real samples; 0.5 means indistinguishable); \emph{MMD$^2$} (squared maximum mean discrepancy, a kernel distance between distributions; 0 means
equal); \emph{precision/recall} (share of synthetic samples that fall near real ones / share of real samples covered by
synthetic ones); \emph{Fr\'echet distance} (the Fr\'echet Inception Distance, FID, formula, computed on the classifier's features); \emph{label agreement} (share of
generated images that the real-trained classifier assigns to the requested class); and \emph{DCR ratio} (median distance
from synthetic samples to their closest training record, divided by the same for held-out real samples; below 1 suggests
copying). Each metric has a \emph{reference}: the value two real samples of the same size give, i.e.\ what a perfect
generator would score.

Then comes the objective test, always against a non-generative baseline: for representation learning, how well the latent
space keeps each cell's 15 nearest neighbors (\emph{trustworthiness}, 0 to 1) compared with PCA of the same size; for
replacing real data, \emph{train on synthetic, test on real} (TSTR): the same classifier trained on $n$ synthetic or $n$
real images and scored on held-out real images, whose ratio is the \emph{utility ratio} (1 means synthetic is as useful as
real); for class balancing, rare-class F1 with synthetic images vs with resampling; for anomaly detection, the AUROC for separating corrupted held-out samples from normal ones, against $k$-nearest-neighbor (kNN)
distance and PCA reconstruction error; for imputation, error on deliberately hidden held-out values, against mean and kNN
imputation.

\textbf{Downstream use.} Each recommended use must cite a metric. The validator checks the cited path and value against
the metrics files, rejects privacy claims (``anonymized'', ``safe to share''), and requires a statement that no formal
privacy guarantee is given whenever sharing comes up.

\section{Tools and AI models used}

Claude Code (headless \code{claude -p}, Claude Opus) is the only AI model involved. Models and metrics use PyTorch 2.14,
NumPy, SciPy, and scikit-learn; figures and reports use Matplotlib. The metric choice follows common practice for
synthetic data; the synthcity benchmark (Qian et al., NeurIPS 2023) was the reference for tabular fidelity and privacy
metrics. VAE samples are drawn from a 10-component Gaussian mixture fit to the training latent codes, instead of the
standard normal prior (ex-post density estimation, Ghosh et al., ICLR 2020).

\section{Results}

The PBMC and PathMNIST numbers below come from the clean runs that produced generated reports 1 and 2, each one
\code{./run.sh} command on a fresh clone. The other objectives were run as rehearsals of the same pipeline.

\textbf{PBMC 3k} (2,700 cells $\times$ 32,738 genes, 97.4\% zeros, raw counts, no labels). Objective: ``Learn a
low-dimensional representation and generate realistic synthetic cells for sharing.'' The agent read this as
representation learning plus data generation. It kept the 2,000 most variable genes, held out 20\% of cells, and chose an
NB VAE on raw counts (latent size 10) as the primary model, with a RealNVP flow on 20 principal components as the
comparator. The critic found that the flow overfit from epoch 13 and that the two models could not be ranked because
the spread between seeds was as large as the gap between them. The revision made the flow smaller, lowered its learning
rate, and gave both models a third seed. Values below are for seeds 0 / 1 / 2.

The VAE reproduces per-gene statistics (correlation with held-out real data: 0.998 for means, 0.99 for zero
fractions; median library size within 2\%), but a classifier still separates its cells from real ones (C2ST 0.84--0.87),

copying. The flow covers the real cells (recall 0.97--0.98), but 38--46\% of its samples are not near any real cell.
The agent reported that both parts of its success criterion failed, recommended neither the latent codes nor the
synthetic cells as stand-ins for real cells, allowed the synthetic counts only as example data for software that
processes count matrices, and stated that no formal privacy guarantee is given.

\textbf{PathMNIST} (89,996 $28\times28\times3$ images, 9 tissue classes, largest/smallest class ratio 1.63). Objective:
``Generate realistic tissue images of each class that could replace the real data for training a tissue classifier.''
The agent trained conditional diffusion (100 epochs, one seed, 20 minutes on the laptop GPU) on a stratified
20,000-image subsample and ran TSTR with $n=10{,}000$ and three classifier seeds per arm. The critic noted that
validation loss was still falling at the last epoch, that the guidance setting's stated reason did not match the low
recall, and that with no comparator the run could not say whether the shortfall was specific to diffusion. A longer
retrain did not fit the remaining budget, so the revision added a conditional GAN (two seeds, 25 epochs) as the
comparator and listed undertraining as a limitation.

The synthetic images cannot replace real ones: a classifier trained on diffusion images loses 25 accuracy points, and
generated class-6 images are recognized as their class only 63\% of the time. The GAN is worse on every metric. Its
recall of 0.07 means its images cover only a small part of the real image types, and most are not recognized as the
requested class, so the shortfall is not specific to diffusion. The agent recommended against replacement for both
models and allowed the diffusion images only as illustrative examples. In an earlier rehearsal of the same command the
critic's finding led instead to a 155-epoch retrain, which raised the diffusion utility ratio from 0.66 to 0.84: longer
training helps, but even then the images fell short of replacing real data.

\textbf{Robustness: other objectives on the same data.} On PBMC, ``Recover gene expression values lost to dropout'' was
read as imputation. The agent trained only the VAE (the only family the imputation test supports) and hid 10\% of each
held-out cell's nonzero counts. The VAE's RMSE on $\log(1+\text{count})$ was 0.512, against 0.550 for the
library-scaled mean and 0.633 for kNN. Its verdict was \emph{conditional}: usable before exploratory analysis, but not
evidence that any given zero is a dropout.

``Flag unusual cells that may be doublets or low-quality captures'' was read as anomaly detection. The agent trained the
NB VAE, scoring cells by their negative ELBO (evidence lower bound), and a flow on PCA components as comparator, two seeds
each, and tested them on held-out cells mixed with simulated doublets (two cells' counts summed) and gene-shuffled cells.
On doublets the VAE reached AUROC 0.935, against 0.708 for kNN distance. The flow (0.14) and PCA reconstruction (0.11)
rated doublets as \emph{more} typical than real cells; one untested explanation is that after normalization a doublet
is an average of two cells and lies near the center of the data. Every method detected gene-shuffled cells (AUROC
0.995--1.0), so the VAE adds nothing there. The one positive verdict was conditional: use the VAE score to shortlist
possible doublets for manual review, alongside the usual cutoffs on total counts and genes detected, because no real
doublets or low-quality cells were tested.

During development, ``Balance the rarest tissue class to improve a classifier'' on PathMNIST ran the headroom check:
accuracy was 0.912 on real data, 0.923 with resampling, and 0.923 with new real images of the rare class. At this mild
imbalance even perfect synthetic images could not beat resampling, and adding diffusion images gave 0.909.

\textbf{When a GAN runs.} The rules make conditional diffusion the primary model for labeled images, because it trains
stably and follows the class label reliably; a GAN enters only as a comparator with a stated reason, and always with at
least two seeds because its results depend strongly on the seed. The validator excludes GANs from anomaly detection,
imputation, and representation learning, since a GAN has neither a likelihood nor an encoder. In the clean PathMNIST
run the GAN entered after the critique, and its low recall matched the expected weakness (covering few image types).

\section{Strengths and limitations}

\textbf{Strengths.}
\begin{itemize}
\item \emph{It tests the user's goal, not just sample quality.} Each objective maps to a fixed test on held-out real
  data against a non-generative baseline, so negative results are reported as such. In every run above the verdicts
  matched the numbers, including ``not recommended'' for both main objectives.
\item \emph{Decisions are checked in code.} Validators reject a model that lacks the needed capability, vague reasons,
  budget overruns, uncited downstream claims, and privacy claims. The headroom check keeps the agent from promising
  gains that even new real data would not give.
\item \emph{The critique changed results.} On PathMNIST it added a GAN comparator in the clean run, which showed the
  shortfall is not specific to diffusion, and in a rehearsal it led to a retrain that raised the utility ratio from 0.66
  to 0.84. On PBMC it fixed an overfit comparator and added a third seed to each model.
\item \emph{Isolation and reproducibility.} One command, an isolated environment, seeded training, and a run that loads
  no user settings and can execute only the project's scripts.
\end{itemize}

\textbf{Limitations.}
\begin{itemize}
\item \emph{Small models and budgets.} Models are sized for a laptop and a 30-minute training budget. Image Fr\'echet
  distances use a small PathMNIST classifier, not the Inception network, so they are not comparable to published FIDs.
\item \emph{Few seeds, one split.} Most results use two or three seeds on one held-out split (the PathMNIST diffusion
  model has one), so the reported spread covers training noise, not variation across splits or masks.
\item \emph{Limited task coverage.} Uncertainty quantification has no test and is always declined or adapted; class
  balancing is tested only on images; categorical tabular features are not supported.
\item \emph{No privacy guarantee.} The DCR ratio is evidence against copying, not differential privacy.
\item \emph{Run-to-run variation.} The agent's decisions are not deterministic. For the same PathMNIST command, the clean
  run answered the critique with a GAN comparator and a rehearsal with a longer retrain (final utility ratios 0.72 and
  0.84). A retrain can nearly double the run time (about 65 minutes in the rehearsal).
\item \emph{Issue found in rehearsal.} One run lost write access after the agent ran \code{cd}, because path permissions
  were relative to the working directory. \code{run.sh} now passes absolute path rules and denies \code{cd}.
\end{itemize}
